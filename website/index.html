Frequently asked questions

How do I install AniLumos?

Download the official stable APK and open it on your Android device. Android may ask you to allow installation from your browser; only install files from sources you trust.

Is Android TV supported?

TV editions are experimental and are not listed on this stable download page.

Where can I report a problem?

Use the GitHub issue tracker.
